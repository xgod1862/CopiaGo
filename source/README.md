# CopiaGo

同一局域网内，iPhone 复制内容后，直接在 Windows 应用中粘贴。手机无需安装 App。

## 安装与首次配对

- 运行安装包。可选择安装目录和登录 Windows 时自动启动。安装完成后，应用会从任务栏右下角的图标上方弹出面板，按面板里的步骤配对；配对、历史和设置都在这一个面板里。
- 如果引导显示缺少 Apple 连接组件，点击「安装 Apple 连接组件」，按 Windows 提示完成安装。安装失败时，可在 Microsoft Store 安装「Apple Devices」。
- 解锁 iPhone 并用数据线连接电脑，点击「连接 iPhone」。手机弹出提示时点「信任」并输入锁屏密码。
- 如果应用提示开启开发者模式，在 iPhone「设置 → 隐私与安全性 → 开发者模式」中开启，按提示重启，解锁后点「打开」。应用会自动继续。首次准备开发者服务时，请保持电脑联网。
- 第三步会提示开发组件下载、Apple 签名或安装出错。根据提示检查网络或手机连接后，点击「继续连接」重试。
- 显示「已连接」后拔掉数据线，等待状态显示「已连接（无线）」。日常使用只需复制和粘贴。
- 换手机或连接异常时，可在面板设置页中点「忘记此 iPhone」（3 秒内再点一次确认），再重新配对。

## 托盘与历史

- 单击系统托盘图标可查看历史。点击记录选中后，用卡片上的复制按钮、双击或按 Enter 复制到 Windows 剪贴板；↑↓ 切换选择，Delete 删除。右上角按钮切换到设置页（开机启动、历史、通知、忘记此 iPhone），左上角返回。托盘右键菜单也可打开「连接与设置」或退出。
- 面板里有两个列表：「iPhone」是从手机同步来的内容，「电脑」是在这台电脑上复制的内容。←→ 键切换。
- 两个列表分别由设置中的「保留 iPhone 剪贴板历史」和「保留电脑剪贴板历史」控制，都默认关闭，也可以在空列表里直接开启。每个列表最多 50 条、内容总量 128 MiB，可删除单条或单独清空。关闭开关会暂停记录新内容，已保存记录可手动删除。
- 电脑列表不会记录密码管理器等标记为敏感的内容，也不会记录本应用自己写入的内容（从手机同步来的、从历史复制的）。选中电脑列表中的一项，用卡片上的上传按钮发到 iPhone。
- 安装包默认关闭历史。历史正文和预览通过 Windows DPAPI 加密，通常需要原电脑上的原 Windows 帐户才能解密。历史仅保存在此电脑。
- 支持文字、图片，以及从「文件」App 复制的文件。照片里的视频暂不支持，复制时面板顶部会给出提示，电脑剪贴板保持不变。
- 文件以原文件名保存到数据目录的 `received` 文件夹，并像在资源管理器中复制文件一样放入剪贴板，可在资源管理器、聊天软件等处直接粘贴。这些文件保留 24 小时，总量超过 2 GB 时先清理最早的。
- 「大文件先询问」（默认 20 MB）：超过这个大小的文件不会自动传输，面板顶部出现「同步到电脑 / 忽略」，面板未打开时还会弹出通知。传输前只读取文件名和大小，选择忽略不会产生传输。单个文件上限 512 MB。关闭「自动同步到电脑」时，文件同样会等你选择。
- 复制同时提供图片和文字时，向 Windows 写入图片。只提供文本或文件名的复制来源无法还原成图片。在这种应用中可以先将图片保存到「照片」，再复制图片。

## 设置

- 安装器和应用默认按 Windows 显示语言选择简体中文或英文。应用在「设置 → 语言」可切换简体中文、English 或跟随系统。配对页右上角的设置按钮在首次配对前就可使用。

- 设置页按方向分组：「iPhone → 电脑」「电脑 → iPhone」各有自动同步开关、同步内容（文字、图片，可多选，至少保留一种）和对应列表的历史开关；「通用」里是开机启动和通知。内容较多时可用滚轮滚动。
- 「同步内容」只影响自动同步和历史记录；从列表复制或发送不受限制。关掉的类型会被静默跳过，不再提示。

## iPhone 到电脑

- 设置中的「自动同步 iPhone 剪贴板到电脑」默认打开。关闭后，iPhone 上的复制不再自动写入电脑剪贴板：开启了 iPhone 剪贴板历史时会进入 iPhone 列表，可以从列表复制；最新一条也可以从托盘菜单「使用 iPhone 上最新复制的内容」写入电脑。

## 电脑到 iPhone

- 开启「保留电脑剪贴板历史」后，电脑列表里每一项都可以用卡片上的上传按钮发到手机。
- 设置中的「自动同步电脑剪贴板到 iPhone」默认关闭。打开后，电脑上每次新复制的文字或图片会自动发到手机；打开开关本身不会发送当前内容。
- 被密码管理器等标记为敏感（不进入剪贴板历史或云剪贴板）的内容一律不发送；从手机同步过来的内容也不会被发回手机。
- 反向同步意味着这台电脑可以改写手机剪贴板。只在可信的电脑上打开自动同步。

## 通知

- 同步成功、出错或断开超过 5 分钟时，应用会显示 Windows 通知。通知只说明内容类型，不显示内容。可在设置中关闭。
- iPhone 短暂休眠导致的断开不会立即提醒；托盘图标在断开 30 秒后变灰。
- 如果 iPhone 在断线期间复制了内容，而重连前电脑上又复制了别的内容，应用不会用 iPhone 上较旧的内容覆盖，可从托盘菜单「使用 iPhone 上最新复制的内容」手动使用。

## 连接与隐私

- Wi-Fi 内容经已配对设备的 TLS 1.2 PSK 隧道传输。该连接使用 iPhone 开发者服务，需保持开发者模式。关闭开发者模式后，已加载的开发者服务会保留到 iPhone 重启，所以重启前仍可同步。更新 iOS 后的兼容性因版本而异。
- 无线配对记录含有可连接这台 iPhone 的私钥，应用用 Windows DPAPI 加密保存，只有原电脑上的原 Windows 帐户能解开；复制走数据目录也无法使用。它防不了以你的帐户运行的恶意程序，所以只在可信的电脑上配对，不用时在设置中「忘记此 iPhone」。
- 来自手机的图片只按 iPhone 会使用的格式（PNG、JPEG、HEIF、TIFF、GIF、WebP、BMP）解码，超过 64 MB 或 5000 万像素的图片不会同步。
- Windows 系统剪贴板仍可正常粘贴。应用为同步内容写入 Windows 系统历史及云同步排除标记。
- 常规安装的配对及历史数据在 `%LOCALAPPDATA%\iPhoneClipboardPrototype`。便携版在程序目录下的 `data`。卸载时会询问是否一并删除这些数据（默认保留）。
- 托盘异常记录在同一数据目录下的 `tray-errors.log`，包含发生时间、异常类型和调用位置。

## 开发与来源

使用带 Tk 的 64 位 Python 3.12。在源码目录安装 `requirements.txt` 后，运行 `build.ps1` 构建。安装包由 `setup.iss` 生成，需 Inno Setup 和简体中文语言文件。

- 开发者模式：https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device.md
- Windows 剪贴板格式：https://learn.microsoft.com/en-us/windows/win32/dataxchg/clipboard-formats
- Windows DPAPI：https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata
- 连接与剪贴板协议实现：https://github.com/doronz88/pymobiledevice3
- Windows 多接口发现参考：https://github.com/williamcachamwri/Relais
